# Mahakam Moonlight Studio

Studio kreatif indie satu orang dari Tenggarong, Kalimantan Timur - membangun aplikasi web yang ringan, cepat, dan bekerja di mana saja, termasuk shared hosting.

**Stack utama:** PHP · MySQL · Tailwind CSS v4 · Vanilla JavaScript · PWA
